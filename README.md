# MedCard 2026

Marketing site for MedCard 2026 — a patient-centric medical records platform.
Built as an investor-facing landing page: problem/solution, product overview,
market opportunity, business model, roadmap, team, and investor contact.

## Stack

- [Vite](https://vite.dev) + React
- [Tailwind CSS v4](https://tailwindcss.com)

## Development

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
```

## Structure

- `src/App.jsx` — page composition
- `src/components/` — one component per section (Hero, Problem, Product, Market, etc.)
- `src/index.css` — theme tokens (colors, fonts) and global styles

Content (copy, stats, team bios, roadmap milestones) is placeholder and should
be updated with real figures as they become available.
